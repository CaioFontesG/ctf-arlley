Regras

01 O alvo é exclusivamente a aplicação web no endereço fornecido. Ataques ao host, infraestrutura ou outros participantes resultam em desclassificação.
02 Cada desafio tem uma flag no formato FLAG{...}. Submeta no CTFd ao resolver cada desafio.
03 Todas as ferramentas são permitidas. Kali Linux é recomendado mas não obrigatório.
04 DoS, DDoS, brute-force excessivo ou qualquer ação que degrade o serviço para outros participantes é proibida.
05 Quem submeter a flag correta primeiro vence. O ranking é automático e registra o timestamp.
